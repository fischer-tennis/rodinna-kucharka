RODINNÁ KUCHÁRKA – VERZIA 2.0.1 STABLE

Táto aktualizácia zachováva pôvodný vzhľad aplikácie, spodnú navigáciu, kategórie,
obľúbené recepty, prihlasovanie, spoločnú kontrolu receptov a cloudové funkcie.

Doplnené:
- pomocník na bezplatný prepis receptu cez ChatGPT bez API,
- odfotenie alebo výber fotografie receptu,
- náhľad fotografie a nastavenie ako originál zo zošita,
- kopírovanie pripraveného zadania,
- otvorenie ChatGPT,
- vloženie odpovede a vyplnenie polí receptu,
- zabudnuté heslo,
- lepšie chybové hlášky a bezpečnejšie ukladanie fotografií,
- nová cache Service Workera.

NAHRATIE NA GITHUB
Nahraď iba tieto 4 súbory:
1. index.html
2. app.js
